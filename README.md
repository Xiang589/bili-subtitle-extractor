# bili-subtitle-extractor

一个本地优先的 Tampermonkey/油猴脚本，用于在用户打开 Bilibili 视频页时提取当前视频已有字幕，并导出为 AI 可读文档。

第一版只做字幕提取，不做视频下载、ASR、画面识别、批量抓取、登录绕过或云端服务。

## 功能列表

- 在 Bilibili 视频页右下角显示“提取字幕”按钮。
- 注册 Tampermonkey 菜单命令“提取当前 B 站字幕”。
- 自动识别当前视频 BV 号和分 P。
- 优先读取页面内的 `__INITIAL_STATE__`，必要时调用 Bilibili 视频信息接口获取 aid/cid/分 P 信息。
- 读取当前分 P 的已有字幕轨，并按“中文简体 > 中文 > AI 中文 > 第一个可用轨道”选择字幕。
- 支持导出 Markdown、TXT、SRT、JSON，默认 Markdown。
- 使用浏览器 Blob 在本地下载文件，不上传任何数据。

## 安装方法

1. 安装 Tampermonkey 或其他兼容 userscript 的浏览器扩展。
2. 新建脚本，将 `bili-subtitle-extractor.user.js` 的内容粘贴进去并保存。
3. 也可以从 GitHub 仓库打开 raw 文件，由 Tampermonkey 直接安装。

本项目无 npm 依赖、无构建系统，单文件 userscript 可直接安装。

## 使用方法

1. 打开 `https://www.bilibili.com/video/*` 格式的视频页。
2. 点击页面右下角“提取字幕”，或在 Tampermonkey 菜单中点击“提取当前 B 站字幕”。
3. 如检测到多个字幕轨，可按提示输入序号选择。
4. 按提示选择导出格式：`md`、`txt`、`srt`、`json`，直接回车默认导出 `md`。
5. 文件会在浏览器中本地下载，文件名格式为 `视频标题_BV号_P1.md`。

## 导出格式

- Markdown：包含视频标题、来源、BV 号、CID、分 P、原始链接、字幕语言和带时间段的字幕正文。
- TXT：每行一条纯字幕。
- SRT：标准序号和 `00:00:00,000 --> 00:00:03,500` 时间格式。
- JSON：包含 `title/source/url/bvid/cid/page/track/body` 字段。

## 常见问题

**为什么提示“当前视频没有字幕轨”？**

脚本只读取 Bilibili 当前视频已经存在的字幕。若视频没有字幕，脚本不会生成空文件。

**会下载视频吗？**

不会。本项目不下载视频、不读取视频流、不提取音频。

**会自动识别语音或画面文字吗？**

不会。v0.1 只处理已有字幕，不做 ASR、OCR 或画面识别。

**需要登录才能看的字幕怎么办？**

脚本不会发送 Cookie，也不会绕过登录、付费、会员、地区或权限限制。若字幕接口要求登录或权限校验，脚本会提示后停止。

**多 P 视频会怎么处理？**

v0.1 只处理用户当前主动打开的视频页和当前分 P。URL 中 `p=2` 时会尝试读取 P2 对应的 CID 并导出 P2 字幕。

## 隐私说明

- 只处理用户当前主动打开的视频页。
- 不批量抓取。
- 不下载视频。
- 不上传 Cookie。
- 不上传字幕内容。
- 字幕内容仅通过浏览器 Blob 在本地生成下载文件。
- 脚本请求范围限制在 Bilibili 视频信息接口和字幕 URL 所在域名。

## 合规说明

本项目仅供个人学习、研究、笔记整理。使用者应遵守 Bilibili 平台规则和版权要求。

脚本不绕过登录、付费、会员、地区或权限限制，也不提供云端服务、批量抓取或视频下载能力。
